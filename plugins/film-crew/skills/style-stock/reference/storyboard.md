# Stock storyboard schema

`storyboard.json` is the stock style's shot list. `compile.py` writes it from a
style-neutral beat plan; `fetch.py` mutates it by resolving `clip` objects and
credits; `render.py` consumes it.

Schema version is `1`.

```json
{
  "schema": 1,
  "style": "stock",
  "title": "Ninety Seconds",
  "seed": 41,
  "aspect": "16:9",
  "width": 1920,
  "height": 1080,
  "fps": 30,
  "duration": 117.1,
  "grade": "noir",
  "grade_filter": "...ffmpeg filter chain...",
  "grade_target": 0.4,
  "music": { "mood": "tension" },
  "narration": [ ... ],
  "acts": [ ... ],
  "shots": [ ... ],
  "credits": [ ... ],
  "notes": [ ... ]
}
```

## Top-level fields

| field | required | meaning |
|---|---:|---|
| `schema` | yes | `1`; tools refuse unknown schemas |
| `style` | yes | `stock` |
| `title` | yes | default render filename and title plate text |
| `seed` | no | deterministic score seed and inherited beat-plan seed |
| `aspect` | yes | `16:9`, `9:16` or `1:1` |
| `width`, `height` | yes | `1920x1080`, `1080x1920` or `1080x1080` from `--aspect` |
| `fps` | yes | currently `30` |
| `duration` | yes | full film duration in seconds, including tail |
| `grade` | yes | one of `clinical`, `ember`, `faded`, `noir`, `oceanic`, `verdant` |
| `grade_filter` | yes | ffmpeg filter chain applied to every shot after exposure matching |
| `grade_target` | yes | target luma used by partial auto-exposure |
| `music` | yes | `{ "mood": ... }`, consumed by `score.py` |
| `narration` | yes | line timing and optional audio paths |
| `acts` | no | copied through from the beat plan; used for title subtitle |
| `shots` | yes | ordered stock shots |
| `credits` | yes | regenerated by `fetch.py` from resolved clips |
| `notes` | yes | warnings and blocking notes from compile/fetch |
| `mix` | no | passed through from the beat plan if present |

## Narration line

```json
{
  "id": "l1",
  "text": "At closing time...",
  "at": 1.2,
  "audio": "vo/l1.wav",
  "duration": 4.8
}
```

`at` is the absolute start time after `timing.lead_in`. `audio` is optional and
relative to the storyboard file. If no narration audio exists, render can still
make a silent visual check.

## Shot

```json
{
  "id": "s07",
  "beat": "b7",
  "at": 15.8,
  "dur": 3.0,
  "intent": "reveal",
  "subject": "a vault door turning slowly",
  "emphasis": 0.85,
  "query": "vault door turning",
  "alternates": ["vault door", "vault"],
  "move": "push-in",
  "move_amount": 1.0,
  "speed": 1.0,
  "grade": "noir",
  "clip": null,
  "keyword": "DOOR"
}
```

| field | required | meaning |
|---|---:|---|
| `id` | yes | `s01`, `s02`, ... in cut order |
| `beat` | yes | source beat id from the beat plan |
| `at` | yes | absolute seconds; first shot is forced to `0.0` |
| `dur` | yes | seconds until the next shot, or to the film end |
| `intent` | yes | beat intent; controls move and speed defaults |
| `subject` | yes | prose description for humans and placeholder text |
| `emphasis` | yes | copied from beat or default `0.5`; controls keyword plates |
| `query` | yes | primary footage query |
| `alternates` | yes | fallback queries, already widened |
| `move` | yes | `hold`, `push-in`, `drift-left`, `drift-right`, `drift-up` |
| `move_amount` | yes | scalar applied by render; motion plan may change it |
| `speed` | yes | playback speed; `evidence` `0.92`, `portrait` `0.94`, `transition` `1.08`, others `1.0` |
| `grade` | yes | same as top-level grade |
| `clip` | yes | `null` until resolved by `fetch.py` |
| `keyword` | no | upper-case chip drawn by PIL if present |
| `placeholder` | no | `unphotographable`, `no-footage` or `download-failed` |
| `tier` | no | motion-plan tier applied by `compile.py --motion-plan` |
| `impact_at` | no | recorded for impact tiers |

A missing clip is not a crash. `render.py` creates a labelled `NO FOOTAGE`
segment of the correct duration so the clock stays true and the failure is
visible.

## Clip

After `fetch.py`, a shot's `clip` is a local, credited source:

```json
{
  "source": "pexels",
  "id": "39060937",
  "page": "https://www.pexels.com/video/.../",
  "author": "Kiwi and Camera",
  "author_url": "https://www.pexels.com/@kiwi-and-camera-2158354883",
  "license": "Pexels",
  "width": 1920,
  "height": 1080,
  "fps": 25.0,
  "quality": null,
  "duration": 24.0,
  "query": "bank vault door",
  "upscaled": false,
  "short": false,
  "file": "footage/pexels-39060937-1920x1080.mp4"
}
```

Never expect `quality` to be meaningful. It is often `null`. Branch on pixel
area and the `upscaled` flag, not on `quality`.

There is deliberately no `url` after download. Pexels `video_files[].link`
values are signed, time-limited Vimeo CDN URLs. `fetch.py` removes them so a
later stage cannot try to use an expired URL when the file is already on disk.

## Credits

Credits are flat because `rights-manager` should not need to understand the
storyboard structure:

```json
{
  "file": "footage/pexels-3727447-1920x1080.mp4",
  "license": "Pexels",
  "credit": "Video by German Korb on Pexels",
  "author": "German Korb",
  "author_url": "https://www.pexels.com/@german-korb-1920614",
  "page": "https://www.pexels.com/video/.../",
  "source": "pexels"
}
```

`fetch.py` also writes the same list to `assets.json` beside the storyboard on
every non-dry run. The ledger is regenerated from the resolved shots, so it
cannot drift from the cut.

## Notes

Notes are dictionaries with `level` and text. `blocking` means the stage exits
non-zero. Render may still make placeholders, but do not ship past a blocking
note.

```json
{
  "level": "blocking",
  "beat": "b12",
  "shot": "s12",
  "note": "no footage: no result for any of ..."
}
```
