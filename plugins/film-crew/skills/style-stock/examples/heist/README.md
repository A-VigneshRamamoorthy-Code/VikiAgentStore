# Heist demo: Ninety Seconds

This is the bundled stock-style demo film. It is a 44-shot, 2m15s heist
story called **Ninety Seconds**, narrated by the voice-booth cast voice
`imogen` and delivered at 1920x1080, -14.0 LUFS.

Files:

| file | purpose |
|---|---|
| `beat-plan.json` | style-neutral input from the storyboard artist |
| `storyboard.json` | compiled and fetched stock storyboard |
| `assets.json` | flat credit ledger generated by `fetch.py` |
| `heist_sheet.jpg` | contact sheet gate for the resolved cut |
| `lines.json` | narration lines fed to `voice-booth/scripts/narrate.py` |
| `footage/` | downloaded clips + search cache — **not committed** |
| `vo/`, `*.mp4` | narration and the finished film — **not committed** |

The story opens at closing time, moves through a vault, alarm and car chase,
then reveals that the money was the distraction and the records were the theft.
The compiler chooses `noir` for the grade and `tension` for the music mood from
the story's own words.

## No footage ships with this demo

`footage/` is 435 MB, the narration is 10 MB and the film is 96 MB, and none of
it is in git. That is not only a size decision: the Pexels licence forbids
redistributing the clips as stock, and bundling 44 raw mp4s into an installable
plugin is exactly that.

Instead **`storyboard.json` is a lockfile**. Every shot pins the provider and
the clip id, so the exact film can be rebuilt from a fresh clone. What is
deliberately *not* stored is the download URL, which is a signed Vimeo link
that expires within the hour; `fetch.py` asks the API for a fresh one per
pinned id.

So on a clone with an empty `footage/`, this restores the identical cut:

```bash
python3 ../../scripts/fetch.py storyboard.json
```

Measured: 44/44 clips restored in 69s, 369 MB, all 44 ids byte-identical to the
committed lockfile. `fetch.py` checks that each pinned file is actually on disk
rather than trusting the record — believing the record reported "44/44 shots
have footage" over an empty directory.

To rebuild the voice and the film as well:

```bash
python3 ../../../voice-booth/scripts/narrate.py lines.json -o vo --voice imogen
python3 ../../scripts/render.py storyboard.json -o ninety-seconds.mp4 -j 8
```

Useful commands from this directory:

```bash
python3 ../../scripts/compile.py beat-plan.json --check
python3 ../../scripts/compile.py beat-plan.json -o storyboard.json
python3 ../../scripts/fetch.py storyboard.json
python3 ../../scripts/render.py storyboard.json --sheet heist_sheet.jpg
python3 ../../scripts/render.py storyboard.json -o ninety-seconds.mp4
```

The demo is also the regression case for synthetic-footage rejection. A flat
cyan cartoon bank once landed at the twist among rainy night clips. The current
fetcher rejects that class of clip with the temporal identical-pixel test and
re-shoots the beat.
