# Heist demo: Ninety Seconds

This is the bundled stock-style demo film. It is a 44-shot, roughly 117-second
heist story called **Ninety Seconds**.

Files:

| file | purpose |
|---|---|
| `beat-plan.json` | style-neutral input from the storyboard artist |
| `storyboard.json` | compiled and fetched stock storyboard |
| `assets.json` | flat credit ledger generated by `fetch.py` |
| `heist_sheet.jpg` | contact sheet gate for the resolved cut |
| `footage/` | downloaded Pexels clips and search cache |

The story opens at closing time, moves through a vault, alarm and car chase,
then reveals that the money was the distraction and the records were the theft.
The compiler chooses `noir` for the grade and `tension` for the music mood from
the story's own words.

Useful commands from this directory:

```bash
python3 ../../scripts/compile.py beat-plan.json --check
python3 ../../scripts/compile.py beat-plan.json -o storyboard.json
python3 ../../scripts/fetch.py storyboard.json
python3 ../../scripts/render.py storyboard.json --sheet heist_sheet.jpg
python3 ../../scripts/render.py storyboard.json -o ninety-seconds.mp4
```

The demo is also the regression case for synthetic-footage rejection. A flat
cyan cartoon bank once landed at the twist among rainy night clips. The current
fetcher rejects that class of clip with the temporal identical-pixel test and
re-shoots the beat.
